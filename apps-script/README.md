# 線上訂單接到 Google 試算表（Apps Script 設定）

網站結帳送出後，訂單會寫入試算表的「訂單」工作表，金額由伺服器重新計算。

## 一、建立試算表與程式

1. 在 Google 試算表建立一份新的試算表，例如「金邊鍋貼訂單」。
2. 上方選單點 **擴充功能 → Apps Script**。
3. 把編輯器裡的預設程式全部刪除，貼上 `apps-script/Code.gs` 的全部內容。
4. 按 **儲存**（磁碟圖示）。

## 二、設定 token 與通知（選用）

1. 左側點 **專案設定**（齒輪圖示）。
2. 拉到 **指令碼屬性** → **新增指令碼屬性**：
   - 屬性：`ORDER_TOKEN`
   - 值：`d35bfeef0325e50132ee2fb9476d60c8`（需與 `index.html` 的 `ORDER_TOKEN` 相同）
3. 如果要收到新訂單的 Email，再新增一筆：
   - 屬性：`NOTIFY_EMAIL`
   - 值：收件信箱（不要寫進程式碼或公開的檔案裡）

## 三、部署為網頁應用程式

1. 右上角點 **部署 → 新增部署作業**。
2. 類型選 **網頁應用程式**。
3. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 點 **部署**，依提示授權（會要求存取試算表與寄信權限）。
5. 複製產生的 **網頁應用程式網址**（結尾是 `/exec`）。

## 四、測試

- 用瀏覽器打開部署網址，應該會看到 `{"ok":true,"service":"orders"}`。
- 把網址提供給網站設定（`index.html` 的 `ORDER_API`），再從網站送出一筆測試訂單，試算表應出現新的一列，狀態為「待確認」。

## 修改程式後

修改 `Code.gs` 後，要到 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本 → 部署**，網址才會更新為最新程式。

## 注意

- 這個 token 會出現在網站原始碼中，只能防止隨意亂送，不能當成真正的密碼。
- 網站目前只收集訂單，不處理付款。
- 商品價格同時存在 `index.html` 與 `Code.gs` 的 `CATALOG`，改價格時兩邊都要改。
